# 阶段 09：合规、测试与工程化

## 阶段目标

- 理解合规辅助筛查的设计：只做线索筛查、robots 仍是唯一硬闸门；
- 掌握项目的测试体系：单元测试不联网、集成测试按需启用；
- 能把项目打包成可发布的 exe，并用自检验证产物。

## 9.1 合规辅助筛查：`core/compliance/`

定位一句话：**扫描目标站点公开的法律/政策页面，筛出与爬虫相关的条款，输出结构化线索报告；不构成法律意见，不判断"能不能抓"**。

流水线：

```
discovery(法律页发现：页脚入口/sitemap/常见路径)
   → extract(正文与条款切分)
   → classifier(本地关键词+打分基线)
   → llm(可选：OpenAI 兼容接口辅助标注，失败自动降级)
   → report(JSON / Markdown / HTML)
   → scanner(ComplianceScanThread 编排)
```

安全设计（教学价值极高，逐条体会）：

| 机制 | 位置 | 防的是什么 |
|---|---|---|
| `guard` 免责与结论拦截 | `guard.py` | 报告出现"可以抓/不可以抓"式结论 → 命中即替换为"需人工确认"，附录报告拦截数 |
| 引文防幻觉 | `guard.py` + `llm.py` | LLM 返回的引文必须在本地原文**逐字匹配**才采纳，否则丢弃并计数 |
| 降级不降能 | `llm.py` / `classifier.py` | 未配 Key 或调用失败 → 纯本地关键词检测，功能不受影响 |
| 确定性失败立即停 | `llm.py` | 403/404 立即停止重试并给可读原因；只有 429/5xx 才退避重试 |
| 分批部分成功保留 | `llm.py` | 某批失败时已成功批次的标注保留，报告写明降级原因 |
| 隐私最小化 | `llm.py` | 只发候选条款片段（默认 30 条 × 600 字符），不发整页 HTML |
| 扫描自律 | `discovery.py` / `config.py` | 仅同站公开页面、自身遵守 robots.txt、最多 12 页、页间约 1 秒；不登录、不绕付费墙 |

**robots.txt 仍是唯一硬性闸门**：合规报告不参与任何自动放行/阻断决策；单页 403/404 只跳过该页并写明原因，不中断扫描。

## 9.2 测试体系：`tests/`

```bash
python -m pytest tests/ -q                                  # 单元测试：不需要浏览器、不访问网络
python -m pytest tests/ -m "not integration" -q             # 显式排除集成测试
python -m pytest tests/test_browser_session_integration.py -v   # 集成测试（条件不足自动 skip）
set CS_INTEGRATION_LAUNCH=1                                 # 需要真正启动浏览器时才设
python -m unittest discover -s tests                        # 没有 pytest 也能跑
```

设计要点：

- `conftest.py` 把项目根加入 `sys.path`，注册 `integration` 标记（默认不选）；
- 单元测试用**替身**（驱动替身、请求替身、临时目录）把"被测逻辑"与"真实环境"隔离——这是测试可以既快又不联网的原因；
- 集成测试默认只读探测；真正启动浏览器需要显式开闸（`CS_INTEGRATION_LAUNCH=1`），避免开发机上意外弹窗；
- 每个子模块都有对应测试文件，测试名即文档（读测试名就能知道模块对外承诺了什么行为）。

## 9.3 打包与发布：`crawler.spec`

```bash
pip install pyinstaller
pyinstaller crawler.spec --noconfirm                  # 常规构建：dist\FullAICrawler.exe（约92MB）
set BUILD_CONSOLE=1 && pyinstaller crawler.spec --noconfirm   # 控制台版（排查用）：FullAICrawler-debug.exe
set BUNDLE_BROWSER=1 && pyinstaller crawler.spec --noconfirm  # 内置浏览器内核（约650MB）
```

**验证产物**：

```bash
FullAICrawler-debug.exe --selftest          # 环境自检：路径/数据库/浏览器/Playwright/规则/依赖
FullAICrawler-debug.exe --selftest --gui    # 界面冒烟：创建主窗口数秒后自动退出
```

工程决策解读：

- `--onefile` 每次启动都要解压到临时目录 → 默认**不打内核**（启动快、体积小）；
- 打包后内核查找链：`CRAWLER_CHROME_PATH` → exe 同级 `resources\browsers\` → 内置目录 → 系统 Chrome/Edge → PATH → 自动解压同级 `chrome-win64.zip`；
- 推荐分发：exe + `chrome-win64.zip`（或解压好的 `resources\browsers`）放一起，兼顾体积与动态渲染能力；
- exe 同级为可写应用目录，运行期生成 `resources\crawler_cache.db`、`resources\rules\`、`task_data\`、`downloads\`。

## 9.5 动手练习

1. **测试全绿**：`python -m pytest tests/ -q` 与 `python -m unittest discover -s tests` 各跑一遍；
2. **写一个单测**：给 `core/parser.py` 的某个函数补一个测试（临时目录/替身思路），跑通；
3. **集成测试**：`python -m pytest tests/test_browser_session_integration.py -v` 看 skip 原因；完全退出浏览器后 `set CS_INTEGRATION_LAUNCH=1` 再跑；
4. **合规报告**：GUI 对 `example.com` 跑一次合规辅助筛查，导出 JSON 报告，逐项核对"已扫描/被跳过"与"需人工确认"标记；
5. **LLM 降级**：不配 Key 跑一次筛查（本地关键词模式）；配置 `CHATANYWHERE_API_KEY` 后再跑，对比报告的标注差异与"拦截结论式表述"计数；
6. **打包**：打一个控制台版 exe，运行 `--selftest` 与 `--selftest --gui`，记录每项结果。
