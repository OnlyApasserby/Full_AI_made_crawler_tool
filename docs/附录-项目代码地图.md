# 附录：项目代码地图

> 全模块职责速查表。本附录来自对 `f:/develop/1919` 的系统性检索调研，配合各阶段文档的"源码精读清单"使用。路径均相对于项目根目录。

## A. 顶层

| 文件 | 职责 |
|---|---|
| `main.py` | 入口：`--selftest`（环境自检）/`--selftest --gui`（界面冒烟）/正常启动；QTimer 唤醒主线程保证 Ctrl+C 可靠触发 |
| `config.py` | 全部默认参数与路径推导（`COMPLIANCE_*` / `LLM_*` / `DEFAULT_SESSION_*` / `default_db_path` 等） |
| `models.py` | 数据模型：任务 / 配置 / 状态 |
| `verify_ebook_fetcher.py` | 电子书抓取的验证脚本 |
| `crawler.spec` | PyInstaller 打包配置（`BUILD_CONSOLE` / `BUNDLE_BROWSER` 开关） |

## B. `core/` 顶层模块

| 文件 | 职责 | 关键学习点 |
|---|---|---|
| `core/crawler.py` | BFS 递归爬取线程 `RecursiveCrawlerThread`（QThread） | 分层 BFS；SHA-256 URL 指纹双去重（会话集+DB）；`threading.Event` 暂停/停止；socket shutdown 中断阻塞请求；随机 UA+代理+抖动；流式读取+停止检查点 |
| `core/downloader.py` | 媒体下载器 `ContentDownloader`（QThread） | `PriorityQueue`+线程池；1MB 分块 + `Range` 断点续传（校验 Content-Range）；`Range:bytes=0-0` 探测；MD5 完整性校验；图片 MD5 + dhash 去重、Pillow 压缩与降级；生成 index.html/resources.txt |
| `core/ebook_fetcher.py` | 电子书正文抓取 `fetch_book(start_url, output_path)` | CSS 选择器优先（bs4+lxml）缺失退正则；正文容器/噪声节点/下一页多级选择器；visited 防死循环 + max_pages；随机延时 + 指数退避；UTF-8 txt + *.meta.json |
| `core/filter.py` | URL 过滤器 `URLFilter` | 白名单→屏蔽正则两级；域名归一化；`threading.Lock` 线程安全、规则实时生效；`should_fetch`/`explain` 分离；过滤统计与样本 |
| `core/media_crawler.py` | 媒体抓取编排线程 `MediaCrawlThread` | 串联 fetcher→extractor→paginator→pipeline；静态不足+JS 特征自动升级渲染（`_should_escalate`）；`BoundedSemaphore` 跨任务限流浏览器；deque 队列 + 翻页 + 详情页两级跟随；站点规则命中优先 |
| `core/paginator.py` | 翻页策略 `Paginator` / `PageRule` | next_link / page_param / api_offset 三策略；auto 只做有信号推断；rel=next 优先；路径末段数字推断；同站判定 |
| `core/parser.py` | 页面解析（纯正则零依赖） | `extract_links` / `extract_media_links` / `extract_text`；urljoin；懒加载属性/srcset/poster/og:video/JS 直链；去 script/style 与实体还原 |
| `core/pipeline.py` | 去重与质量过滤流水线 `MediaPipeline` | 从便宜到昂贵分层过滤（类型→SVG→屏蔽正则→归一化去重→体积尺寸→编号限流）；合集统一重排序号；`FilterStats`；提前过滤 + 下载后落地校验闭环 |
| `core/robots.py` | robots.txt 解析 `RobotsParser` + 在线线程 `RobotsCheckThread` | UA 分组、最长匹配优先、Allow 优先于 Disallow；后台线程抓取供 UI 预览 |
| `core/security.py` | 广告/钓鱼识别与正则生成 | 追踪参数/广告联盟/广告路径；品牌仿冒（同形字符归一化、编辑距离≤1、品牌+诱饵词）；短链/高危 TLD/IP 直连+非常规端口；命中归纳为通用正则供 URLFilter；风险分级与 auto_select |

## C. `core/` 子目录

### `core/fetcher/` 统一抓取层

| 文件 | 职责 | 关键学习点 |
|---|---|---|
| `base.py` | `BaseFetcher` / `FetchContext` / `NetworkEvent` 契约 | 编码推断；可中断睡眠 |
| `requests_fetcher.py` | 静态抓取 | 线程局部 Session 连接池；流式+上限；媒体直链不回读；`fetch_prefix` 头部探测；cookie jar 注入 |
| `playwright_fetcher.py` | 动态渲染抓取 | Chromium 渲染；`page.on(request/response)` 网络监听；自动滚动触懒加载；只采元数据 |
| `browser_pool.py` | 浏览器实例管理 | `threading.local` 生命周期；`BoundedSemaphore` 限流；stealth JS |
| `chrome_setup.py` | 内核查找/解压 | 六级查找链（环境变量→resources/browsers→根目录→系统→PATH→自动解压 zip） |

### `core/extractor/` 提取器插件体系

| 文件 | 职责 | 关键学习点 |
|---|---|---|
| `base.py` | 插件契约 | `can_handle` 置信度 + `extract`；优先级 |
| `registry.py` | 插件发现与调度 | 优先级排序；`extract_all` 合并；`sites/` 即插即用 |
| `generic_html.py` | 通用 HTML 提取 | 每标签取最高质量地址；srcset 最大候选；CSS 背景图；og；缩略图猜原图 |
| `generic_json.py` | 接口 JSON 提取 | 键名具体才采纳（防误报） |
| `network.py` | XHR 监听落地 | 转发请求头过防盗链；过滤埋点/广告域名 |
| `rule_extractor.py` | 站点规则提取 | JSON 规则热加载；bs4 缺失退简化选择器 |

### `core/media/` 媒体领域层

| 文件 | 职责 | 关键学习点 |

## D. `manager/` 任务调度

| 文件 | 职责 | 关键学习点 |
|---|---|---|
| `task_manager.py` | `TaskScheduler`（QObject） | 每任务独立 QThread；仅保留 `max_concurrent` 个存活、按(优先级,ID)排队补位；媒体/文本由 `TaskConfig.media['enabled']` 分流；robots 前置检查线程；进度节流 + `task_queue.json` 防抖持久化；失败重试定时器；信号跨线程回 UI |
| `db_manager.py` | SQLite 集中访问 | 表：`crawled_urls`(url_hash 主键, task_id)、`crawl_tasks`(status=running/completed)、`media_downloads`、`media_items`、`compliance_reports`；`ensure_schema` 建表+旧库补列；`create_crawl_task(resume_task_id)` 续爬；`load_visited_hashes`；WAL + busy_timeout |
| `thread_manager.py` | 线程池管理 | `ThreadPoolManager`（QThreadPool 封装，异步落盘）；`spawn_workers`（N 个守护工作线程） |

## H. 依赖清单（`requirements.txt`）

必需：`PyQt6>=6.4`、`requests>=2.28`、`playwright>=1.40`（+ 浏览器内核）、`beautifulsoup4>=4.11`、`lxml>=4.9`。
可选（缺失自动降级）：`Pillow`（图片压缩/尺寸/感知去重）、`pycryptodome`（HLS AES-128）、`cryptography`（Cookie 加密）、`selenium`（备用驱动）、`pyyaml`（YAML 配置示例）、`pytest`（测试）、`pyinstaller`（打包）。
